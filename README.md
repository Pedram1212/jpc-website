# شرکت جلالی پنوماتیک (JPC – Jalali Pneumatic Company)

وب‌سایت صنعتی B2B و کاتالوگ تعاملی تجهیزات پنوماتیک و اتوماسیون هوای فشرده **شرکت جلالی پنوماتیک** به زبان فارسی (`lang="fa" dir="rtl"`).

## ویژگی‌های کلیدی
- **معماری تأمین دوگانه:** معرفی برند تجاری اختصاصی **JPC** در کنار تأمین تجهیزات از برندهای اروپایی (`Festo`, `Norgren`, `Bosch Rexroth`) و سازندگان معتبر آسیایی.
- **سبد استعلام قیمت چندقلمی (Multi-Item RFQ / BOM Drawer):** امکان افزودن چند کالا به لیست استعلام، مدیریت تعداد و ارسال یکپارچه لیست در فرم B2B، واتساپ یا تلگرام.
- **سیستم معادل‌یابی فنی برند JPC (Technical Cross-Reference):** جستجوی کدهای فنی اروپایی و مشاهده سریع معادل ابعادی و فنی موجود در برند اختصاصی JPC به همراه جداول مقایسه فنی HTML در تمامی صفحات.
- **ماشین‌حساب مهندسی محاسبه نیروی جک پنوماتیک:** محاسبه آنی نیروی کورس رفت و برگشت بر حسب `N` و `kgf` و پیشنهاد خودکار جک‌های هم‌سایز از کاتالوگ.
- **موتور جستجوی هوشمند فارسی/انگلیسی:** نرمال‌سازی اعداد فارسی/عربی و حروف و تطبیق با اصطلاحات فنی بازار ایران به همراه پشتیبانی از پارامتر URL جستجو (`?q=`).
- **فونت‌های محلی (Self-Hosted Local Fonts):** بارگذاری فوق‌سریع با فونت‌های `.woff2` محلی (`Vazirmatn` و `JetBrains Mono`) بدون وابستگی به سرورهای خارجی.
- **بهینه‌سازی جامع سئو و موتورهای مولد هوش مصنوعی (SEO & GEO):**
  - پیش‌رندر استاتیک کارت‌های محصولات (Static HTML Pre-Rendering) و اسکیماهای `ItemList` / `Product` در سورس HTML توسط اسکریپت `scripts/build-seo.py`.
  - داده‌های ساختاریافته JSON-LD شامل `Organization` / `LocalBusiness`، `WebSite` (`SearchAction`)، `CollectionPage`، `BreadcrumbList`، `FAQPage` و `ItemList`.
  - فایل‌های راهنمای خزندگان هوش مصنوعی: `llms.txt`، `llms-full.txt`، `robots.txt` و `sitemap.xml`.

## صفحات فرود تخصصی سئو (Category Landing Pages)
- `index.html` — صفحه اصلی، کاتالوگ جامع، جدول معادل‌یابی، پرسش‌های متداول مهندسی و ماشین‌حساب نیروی جک
- `solenoid-valves.html` — صفحه تخصصی شیرهای برقی پنوماتیک
- `pneumatic-cylinders.html` — صفحه تخصصی جک‌های پنوماتیک و محاسبه‌گر نیرو
- `frl-accessories.html` — صفحه تخصصی واحد مراقبت هوا و اتصالات پنوماتیک

## بروزرسانی پیش‌رندر استاتیک و ایندکس هوش مصنوعی (SEO Build Script)
پس از هرگونه ویرایش در فایل محصولات (`assets/js/products-data.js`)، دستور زیر را اجرا کنید تا کارت‌های HTML استاتیک، اسکیماهای JSON-LD محصولات و فایل `llms-full.txt` به‌صورت خودکار بازتولید شوند:

```bash
python3 scripts/build-seo.py
```
