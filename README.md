# شرکت جلالی پنوماتیک (JPC – Jalali Pneumatic Company)

وب‌سایت صنعتی B2B و کاتالوگ تعاملی تجهیزات پنوماتیک و اتوماسیون هوای فشرده **شرکت جلالی پنوماتیک** به زبان فارسی (`lang="fa" dir="rtl"`).

## ویژگی‌های کلیدی
- **معماری تأمین دوگانه:** معرفی برند تجاری اختصاصی **JPC** در کنار تأمین تجهیزات از برندهای اروپایی (`Festo`, `Norgren`, `Bosch Rexroth`) و سازندگان معتبر آسیایی.
- **کاتالوگ تخصصی با فیلتر زنده:** فیلتر آنی بر اساس دسته‌بندی (شیرهای برقی پنوماتیک، جک‌های پنوماتیک، تجهیزات جانبی و مراقبت هوا)، برند و جستجوی کد فنی.
- **مودال استعلام قیمت سریع و اتصال به واتساپ:** تکمیل خودکار نام محصول و کد فنی در فرم استعلام و لینک مستقیم واتساپ.
- **آماده برای SEO و موتورهای هوش مصنوعی (AEO):** شامل داده‌های ساختاریافته `JSON-LD`، نقشه سایت `sitemap.xml`، فایل `robots.txt` و مستند دوزبانه `llms.txt`.

## ساختار فایل‌ها
- `index.html` — صفحه اصلی و کاتالوگ تعاملی
- `assets/css/styles.css` — استایل‌های طراحی صنعتی (Industrial Luxury) با پشتیبانی از تم روشن و تاریک
- `assets/js/config.js` — تنظیمات پایه، اطلاعات تماس، واتساپ و آدرس وب‌هوک فرم‌ها (`SITE_CONFIG`)
- `assets/js/products-data.js` — دیتابیس محصولات کاتالوگ (قابل ویرایش آسان)
- `assets/js/app.js` — منطق فیلتر زنده، شماتیک‌های برداری `SVG` و فرم‌های استعلام
- `llms.txt` / `sitemap.xml` / `robots.txt` — فایل‌های سئو و AEO
